# Dynamic Turkish Dictionary (Dinamik Türkçe Sözlük)
Bu proje, kapsamlı bir kelime veritabanını modern ve kullanıcı dostu bir arayüzle sunan dinamik bir web uygulamasıdır. Veritabanı mimarisi hazır olarak temin edilmiş olsa da , tüm ön yüz (frontend) tasarımı ve sunucu taraflı arama entegrasyonları sıfırdan geliştirilmiştir.

**Özgün Tasarım:** Hazır şablon kullanılmadan, tamamen projeye özel HTML5 ve CSS3 kodları ile geliştirilen responsive arayüz

**Akıllı Arama ve Öneriler:** AJAX ve Fetch API kullanılarak geliştirilen, kullanıcı yazarken anlık öneriler sunan otomatik tamamlama *(autocomplete)* özelliği

**Gelişmiş Sıralama:** Arama sonuçlarında tam eşleşen kelimelerin en üstte yer almasını sağlayan özel SQL sorgu mantığı

**Modern Kullanıcı Deneyimi:** JavaScript ile güçlendirilmiş pürüzsüz kaydırma *(smooth scroll)* ve dinamik içerik yükleme bileşenleri

# Teknik Altyapı:

**Backend:** PHP

**Veritabanı:** MySQL *(Prepared Statements ile güvenli sorgulama)*

**Frontend:** Vanilla JavaScript (*ES6+)*, CSS3 *(Custom Grid & Media Queries)*, HTML5 

**Geliştirme Ortamı:** Visual Studio Code, WampServer
